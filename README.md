# WhichToKeep

Support and legal pages for WhichToKeep.

Published with GitHub Pages (Jekyll, theme `jekyll-theme-minimal`): no cookies, no analytics, no external scripts.

- `index.md` — support page: https://springs-tea.github.io/whichtokeep/
- `privacy.md` — privacy policy: https://springs-tea.github.io/whichtokeep/privacy
- `terms.md` — terms of use: https://springs-tea.github.io/whichtokeep/terms

Each page has three language sections with the anchors `#en`, `#tr` and `#hu`; the app links to them.
Sentences about the on-device model's download host are marked with `<!-- MODEL-HOST -->`.
